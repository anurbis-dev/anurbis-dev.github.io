Panels & windows

Only the four most-used panels ship with a default chord — everything else (Preview, Stamp library, Presets, Atlas browser…) is unbound until you assign one.

Bound by default
  • Alt1 Tools
  • Alt2 Tool Settings
  • Alt3 Layers
  • Alt4 Animation
Assign one of your own
  • Right-click a panel's header → Edit Hotkey…
  • Or File menu → Panels… lists every panel with its current chord
  • A bound chord shows next to the panel name in that list

Everything else

Ships unassigned by default — pick your own from Settings → Hotkeys if you use them often: reset view, split-view toggle, onion skin, symmetry X/Y, sample-all-layers (Bucket/Gradient/Range), gradient dither/region-limit toggle, dither pattern cycle/erase, brush shape toggle, brush size by wheel, import sprite atlas.

Conflicts — assigning a key already in use flags the clash instead of silently overwriting it. Hold-only modifiers (flip/rotate, brush resize, temporary eyedropper) are the exception: several can share the same chord since they only ever fire one at a time, on whichever tool is active.
Chords reflect PixisEditor's shipped defaults — everything above is rebindable from Settings → Hotkeys.
